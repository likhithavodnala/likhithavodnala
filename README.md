## 🚀 Featured Projects

### 🌊 GeoFlood — Real-Time Flood Detection & Prediction Intelligence System

A two-mode geospatial system for post-flood detection and pre-flood risk prediction in the Rispana–Bindal river corridors of Dehradun.

- Used Sentinel-2 NDWI to detect flood extents.
- Spatially intersected flood extents with OpenStreetMap building footprints to identify potentially affected structures.
- Integrated live rainfall data through the Open-Meteo API and severity classification based on IMD thresholds.
- Developed an interactive Streamlit + Folium dashboard with building-level risk visualization and CSV export.

**Tech:** Python · Sentinel-2 · NDWI · GeoPandas · OSMnx · Streamlit · Folium · Open-Meteo API

### 🌾 Smart Crop Planning System Using Machine Learning

A machine-learning-based crop recommendation system integrating village-level soil information with climate data for Gujarat.

- Integrated 14,243 village-level soil records with NASA POWER climate data.
- Compared XGBoost and Random Forest using 5-fold cross-validation.
- Developed an interactive Streamlit application covering 33 districts and 25+ crops.
- Included confidence levels and feature-importance analysis.

**Tech:** Python · XGBoost · Random Forest · Scikit-learn · Pandas · Streamlit · NASA POWER API

### 🏥 Enterprise GIS Healthcare Portal

A role-based web GIS platform for managing and visualizing Hyderabad hospital spatial data.

- Implemented Viewer, Editor, and Admin workflows for controlled spatial-data management.
- Used PostgreSQL/PostGIS for spatial data storage and management.
- Built an interactive Leaflet.js map with search and filtering capabilities.
- Integrated Flask REST APIs for data retrieval, editing, and verification workflows.

**Tech:** PostgreSQL · PostGIS · Flask · Leaflet.js · QGIS · HTML/CSS/JavaScript

## 📚 Other Academic Projects

### 🌱 AI-Based Vegetation Health & Density Mapping

Mapped vegetation health and density across Ludhiana District, Punjab using Resourcesat-2/LISS-III satellite imagery obtained from the ISRO Bhoonidhi Portal.

- Derived NDVI to assess vegetation condition and density across the study area.
- Applied adaptive NDVI classification with AI/ML-assisted post-classification refinement to improve spatial classification beyond fixed-threshold methods.
- Classified vegetation into different health categories and validated the results using Google Earth imagery.

**Tech:** QGIS · Python · Resourcesat-2/LISS-III · NDVI · Remote Sensing · ISRO Bhoonidhi

### 🛰️ Soil Moisture Estimation Using Sentinel-1 SAR

Estimated volumetric soil moisture over agricultural land in Anantapur District, Andhra Pradesh using Sentinel-1 C-band SAR data.

- Processed Sentinel-1 VV/VH imagery through a complete SNAP preprocessing workflow, including orbit correction, radiometric calibration, debursting, speckle filtering, and terrain correction.
- Applied Dubois and Oh backscattering models together with the Topp equation to estimate soil moisture.
- Compared model outputs and mapped the final soil-moisture distribution in QGIS.

**Tech:** Sentinel-1 SAR · SNAP · QGIS · Dubois Model · Oh Model · Topp Model

### 🌫️ Satellite-Based Air Pollution Mapping of Delhi

Analyzed spatial and temporal variations in tropospheric NO₂ over Delhi from 2018–2024 using Sentinel-5P TROPOMI satellite data.

- Processed Sentinel-5P NO₂ data using Google Earth Engine.
- Extracted annual mean NO₂ values and analyzed their temporal variation using Python.
- Produced final maps in QGIS and visualized the annual trends using Matplotlib.

**Tech:** Sentinel-5P TROPOMI · Google Earth Engine · Python · QGIS · Google Colab · Matplotlib

### 💧 Yearly Water Demand Prediction for Paddy — West Bengal

Developed an XGBoost-based irrigation water-demand prediction system for paddy cultivation using weekly multi-year climate and crop data.

- Integrated climate and crop information to model irrigation water requirements.
- Developed and tuned an XGBoost regression model for water-demand prediction.
- Achieved approximately 84% accuracy with R² = 0.8399 and generated annual irrigation water-demand estimates for agricultural planning.

**Tech:** Python · XGBoost · Scikit-learn · NASA POWER API · Pandas · Matplotlib
